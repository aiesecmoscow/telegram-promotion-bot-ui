# Telegram Promotion Bot

WebUI приложение для автоматической рассылки сообщений через Telegram аккаунт пользователя.

## Функциональность

- ✅ Создание и хранение Telegram сессии в browser local storage
- ✅ Настройка cooldown времени между отправками сообщений
- ✅ Удобный интерфейс для ввода списка пользователей и текста сообщения
- ✅ Логгирование всех операций
- ✅ Автоматическое определение и сообщение о банах/ограничениях аккаунта

## Технологии

### Backend
- Node.js + TypeScript
- Express.js
- Telegram Client Library (`telegram`)

### Frontend
- React + TypeScript
- Vite
- CSS3

## Установка и запуск

### Предварительные требования

1. Node.js версии 16 или выше
2. npm или yarn
3. API credentials от Telegram (получить на https://my.telegram.org)

### Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd tg-promotion-ui-bot
```

### Шаг 2: Установка зависимостей

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd frontend
npm install
```

### Шаг 3: Запуск приложения

#### Запуск Backend (в отдельном терминале)

```bash
cd backend
npm run dev
```

Backend будет запущен на `http://localhost:3001`

#### Запуск Frontend (в отдельном терминале)

```bash
cd frontend
npm run dev
```

Frontend будет доступен по адресу, указанному в терминале (обычно `http://localhost:5173`)

## Использование

### 1. Получение API credentials

1. Перейдите на https://my.telegram.org
2. Войдите с помощью вашего номера телефона
3. Перейдите в "API development tools"
4. Создайте новое приложение, если еще не создано
5. Скопируйте `api_id` и `api_hash`

### 2. Аутентификация

1. Откройте приложение в браузере
2. Введите `API ID` и `API Hash`
3. Нажмите "Next"
4. Введите номер телефона в международном формате (например, +79991234567)
5. Введите код подтверждения, отправленный в Telegram
6. Если включена двухфакторная аутентификация, введите пароль

После успешной аутентификации сессия будет сохранена в local storage браузера.

### 3. Отправка сообщений

1. В поле "Usernames" введите список username получателей (по одному на строку)
   - Можно с символом @ или без: `@username` или `username`
2. В поле "Message" введите текст сообщения
3. Установите время задержки между сообщениями (cooldown)
   - Рекомендуется: 10-30 секунд
   - Минимум: 1 секунда
   - Максимум: 300 секунд
4. Нажмите "Start Sending"

### 4. Мониторинг

- **Статус в UI**: После запуска вы увидите сообщение о статусе операции.
- **Детальные логи**: Проверяйте терминал backend для подробной информации:
  - Прогресс отправки
  - Успешные отправки
  - Ошибки
  - Предупреждения о rate limits
  - Информация о бане аккаунта

## Обработка ошибок

Приложение автоматически обрабатывает следующие сценарии:

### FLOOD / SLOWMODE
```
⚠️ RATE LIMIT detected. You may be sending messages too fast.
```
**Решение**: Увеличьте время cooldown между сообщениями

### USER_BANNED
```
⚠️ ACCOUNT BANNED. Cannot send messages.
```
**Решение**: Ваш аккаунт заблокирован. Рассылка автоматически останавливается.

### AUTH_KEY (Session expired)
```
⚠️ SESSION EXPIRED. Please re-authenticate.
```
**Решение**: Выйдите из системы и пройдите аутентификацию заново.

## Безопасность

- ⚠️ **Никогда не делитесь своими API credentials**
- ⚠️ **Не храните сессии на общедоступных компьютерах**
- ⚠️ **Используйте разумные cooldown времена, чтобы избежать блокировки**
- ⚠️ **Не используйте для спама или нарушения правил Telegram**

## Рекомендации

1. **Cooldown время**:
   - Для небольших списков (до 10 пользователей): 10-15 секунд
   - Для средних списков (10-50 пользователей): 20-30 секунд
   - Для больших списков (50+ пользователей): 30-60 секунд

2. **Лимиты Telegram**:
   - Не отправляйте более 20-30 сообщений в час новым контактам
   - Telegram может временно ограничить функциональность при подозрительной активности

3. **Тестирование**:
   - Сначала протестируйте на небольшом списке (2-3 пользователя)
   - Убедитесь, что сообщения доставляются корректно
   - Постепенно увеличивайте объем рассылки

## API Endpoints

### POST /api/init
Инициализация Telegram клиента
```json
{
  "apiId": 12345,
  "apiHash": "your-api-hash",
  "sessionString": "optional-session-string"
}
```

### POST /api/auth/start
Начало процесса аутентификации
```json
{
  "phoneNumber": "+79991234567"
}
```

### POST /api/auth/signin
Вход с кодом подтверждения
```json
{
  "phoneNumber": "+79991234567",
  "phoneCodeHash": "hash-from-start",
  "phoneCode": "12345"
}
```

### POST /api/auth/password
Проверка 2FA пароля
```json
{
  "password": "your-2fa-password"
}
```

### POST /api/send-messages
Запуск рассылки сообщений
```json
{
  "usernames": ["@user1", "@user2"],
  "message": "Hello!",
  "cooldownSeconds": 10
}
```

### GET /api/session
Получение текущей сессии

## Troubleshooting

### Backend не запускается
- Проверьте, что все зависимости установлены: `npm install`
- Убедитесь, что порт 3001 не занят другим приложением

### Frontend не может подключиться к Backend
- Убедитесь, что backend запущен на порту 3001
- Проверьте CORS настройки

### Ошибки аутентификации
- Проверьте правильность API ID и API Hash
- Убедитесь, что номер телефона в международном формате
- Проверьте интернет-соединение

### Сообщения не отправляются
- Проверьте логи backend в терминале
- Убедитесь, что сессия активна
- Проверьте правильность username получателей
